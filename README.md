# Water, gently.

A tiny, dark-mode water tracker for Notion embeds. It stores the current day's amount and goal only in the viewer's browser.

## Publish on GitHub Pages

1. Create a GitHub repository and upload these files.
2. In **Settings → Pages**, set **Source** to **GitHub Actions**. Every push to `main` is then published automatically.
3. After GitHub publishes it, copy `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` into a Notion `/embed` block.

The tracker is intentionally dependency-free: one `index.html` file and no account, server, or data collection.
